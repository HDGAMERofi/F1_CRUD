1. Nome da aplicação

F1 Manager – Sistema de Gerenciamento de Fórmula 1

2. Descrição da aplicação

O F1 Manager é uma aplicação desenvolvida com o objetivo de gerenciar informações relacionadas ao universo da Fórmula 1, permitindo o cadastro e o gerenciamento de pilotos e equipes.

O sistema utiliza operações CRUD (Create, Read, Update e Delete), possibilitando cadastrar, listar, buscar, editar e excluir registros.

Nesta primeira etapa do projeto, foram desenvolvidos os módulos de Pilotos e Equipes.

3. Funcionalidades implementadas

3.1. Gerenciamento de Pilotos

O sistema permite realizar as seguintes operações:

Cadastrar pilotos: inserir novos pilotos no sistema, preenchendo as informações solicitadas.

Listar pilotos: visualizar os pilotos cadastrados.

Buscar pilotos: localizar um piloto específico por meio do número do piloto.

Editar pilotos: atualizar os dados de um piloto já cadastrado.

Excluir pilotos: remover um piloto do sistema.

3.2. Gerenciamento de Equipes

O sistema também permite realizar as seguintes operações:

Cadastrar equipes: inserir novas equipes de Fórmula 1.

Listar equipes: visualizar todas as equipes cadastradas.

Buscar equipes: localizar uma equipe específica por meio do nome da equipe.

Editar equipes: modificar as informações de uma equipe existente.

Excluir equipes: remover uma equipe do sistema.

Verificar as dependências: confira se as ferramentas e bibliotecas necessárias estão instaladas.

Executar a aplicação: utilize o comando de execução correspondente à tecnologia utilizada no desenvolvimento.
